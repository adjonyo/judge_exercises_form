In this project I want to develop a website app where I can upload my video doing an exercises and judge the execution form. I want to cover exercices like:
 wall balls, squats, jm triceps press, deadlift, bench press, dips, inclined biceps curls, biceps curls, rowing, barbell reverse lunges, bulgarian split squats. 
 Feel free to add more exercices so that I can cover as much as possible.
 There are open source project that help to identify patterns in a moving body. Like detect hips, elbow, wrist shoulder etc mouvements. So the idea is to build on top of those project to judge the executed exercice in the uploaded video.
 For example, while executing a bicep curl, the elbow should be fix.
 In a second time the app can give some technical feadback on how you can improve your execution form.
 This web app is doing something similar(not as complete as what I want but you can start by taking it as an example):  https://www.squatjudge.com/account
